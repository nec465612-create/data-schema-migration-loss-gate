## Stage 2 requirements to bind

The contract is one common schema-migration case. The primary schema owner fixes old/new schemas; the mapper supplies an explicit mapping; evaluators judge field-meaning equivalence. The result is `LOSSLESS`, `LOSS_FOUND`, or safe global `UNRESOLVED`. No actual user data claim is made.

The deterministic reducer must enforce exact old/new field structure, one response row per old field, unique targets, safe DROP/default rules, type/cardinality rules, and global UNKNOWN handling. `DROP` is `SKIP_DROP`; structurally incompatible non-DROP rows are `DIFFERENT`; only compatible rows reach the bounded semantic assessment.
